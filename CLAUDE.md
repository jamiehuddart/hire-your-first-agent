# My Game: HIL Course Task 2

My name is Jamie Huddart. I'm a recruiter and headhunter at Harmonic Finance & Operations, a B Corp recruitment firm with its HQ in Shoreditch, London, and I lead Harmonic's internal AI programme.

I would like to create a fun website for the other cohort members of High Intent Labs to learn how to use AI agents. We are career professionals, founders and operators of early-stage businesses. The website should be gamified and we should enjoy playing it. It should give us ideas on the use cases of AI agents just as much as it teaches us how to build them.

The project lives in a GitHub repository.

This is a task on **High Intent Labs (HIL)**, a four-week Claude training course that runs from November to December 2026. The course leader, Seb, sets the task structure.

The product requirements are in `PRD.md`. Read it before building anything, and update it when scope changes.

## Instructions

There is a file in this folder called `MEMORY.md`.
Use `MEMORY.md` to document everything we do in this project:
- what we're learning
- key takeaways
- progress
- any important decisions

Keep `MEMORY.md` up to date at all times, and always update it before a session ends.
Every time we start a new session, read `CLAUDE.md` and `MEMORY.md` first to get the full project context.
